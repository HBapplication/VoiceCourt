# VoiceCourt

מעקב סטטיסטיקות כדורסל בזמן אמת בעזרת פקודות קוליות ("7 איבוד כדור"), עם שעון משחק, בנק מושגים הניתן לעריכה, וגישה מבוססת הרשמה/אישור מנהל דרך Firebase.

זהו PWA (Progressive Web App) - ניתן להתקין אותו כמו אפליקציה רגילה על אנדרואיד ואייפון, בלי חנות אפליקציות.

---

## 1. הקמת פרויקט Firebase (חד פעמי)

1. גשי ל-https://console.firebase.google.com ולחצי "Add project" (הוספת פרויקט). תני שם, למשל `voicecourt`.
2. בתפריט הפרויקט: **Build -> Authentication -> Get started**.
   - הפעילי **Email/Password**.
   - הפעילי **Google** (בחרי אימייל תמיכה בעת ההגדרה).
3. בתפריט: **Build -> Firestore Database -> Create database**. בחרי מצב "Production" (הכללים שכבר נמצאים בקובץ `firestore.rules` יחליפו את ברירת המחדל).
4. בתפריט: **Project settings (גלגל השיניים) -> General -> Your apps -> Add app -> Web (</>)**. תני שם לאפליקציה, **לא** צריך "Firebase Hosting" בשלב הזה אם תעלי ל-GitHub Pages.
5. תעתיקי את אובייקט ה-`firebaseConfig` שמופיע שם, והדביקי אותו בקובץ `firebase-config.js` בפרויקט הזה (מחליפה את הערכים "YOUR_...").

## 2. פריסת כללי האבטחה של Firestore

בקובץ `firestore.rules` יש כללים שמוודאים ש:
- רק משתמש מחובר יכול ליצור לעצמו בקשת גישה (סטטוס "pending").
- רק מנהל/ת יכול/ה לאשר, לחסום, למחוק, או לקדם משתמש למנהל.
- רק משתמש מאושר (status = approved) יכול לקרוא/לכתוב את נתוני הקבוצה (`teamData`, `games`).

להעלות את הכללים: **Firestore Database -> Rules** בקונסולת Firebase, הדביקי את תוכן `firestore.rules` ולחצי Publish.
(אפשר גם עם ה-CLI: `firebase deploy --only firestore:rules`, אם התקנת `firebase-tools`.)

## 3. הפיכת עצמך למנהל/ת ראשון/ה

זו הנקודה החשובה ביותר: **אין** דרך למשתמש להצהיר על עצמו כמנהל מתוך האפליקציה (בכוונה - זו הגנה אמיתית). לכן בפעם הראשונה:

1. פרסי את האפליקציה (ראי סעיף 4) ותירשמי/י דרכה (אימייל+סיסמה, או Google).
2. תראי מסך "ממתין לאישור" - זה תקין.
3. גשי ל-**Firestore Database -> Data** בקונסולת Firebase, פתחי את האוסף `users`, מצאי את המסמך שלך (לפי השם/אימייל שלך).
4. ערכי בו ידנית שני שדות: `role` -> `admin`, `status` -> `approved`.
5. חזרי לאפליקציה (או רעני), ותראי שנפתחה לך גישה מלאה + טאב "ניהול" שממנו את/ה מנהל/ת את כל שאר הבקשות מעתה בלי לגעת בקונסולה שוב.

## 4. פריסה (Deploy)

**אפשרות א' - GitHub Pages (הכי פשוט, בחינם):**
1. צרי repo חדש ב-GitHub, והעלי אליו את כל קבצי הפרויקט הזה (`index.html`, `app.js`, `styles.css`, `manifest.json`, `sw.js`, `firebase-config.js`, `icons/`, `logo.png`).
2. ב-repo: **Settings -> Pages -> Source** בחרי את הברנץ' (למשל `main`) ותיקיית השורש (`/`).
3. אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.
4. **חשוב:** בקונסולת Firebase -> Authentication -> Settings -> Authorized domains, הוסיפי את הדומיין הזה (`<username>.github.io`), אחרת ההתחברות תיכשל.

**אפשרות ב' - Firebase Hosting:**
```
npm install -g firebase-tools
firebase login
firebase init hosting   # בחרי את התיקייה הנוכחית כ-public dir
firebase deploy
```

## 5. התקנה כאפליקציה (PWA) בטלפון

**אנדרואיד (כרום):** נכנסים לכתובת האתר, כרום יציע "התקן אפליקציה" / "Add to Home screen" - לוחצים ומאשרים. אפשר גם דרך תפריט שלוש הנקודות.

**אייפון (ספארי, חובה ספארי ולא כרום):** נכנסים לכתובת האתר בספארי, לוחצים על כפתור השיתוף (הריבוע עם החץ), גוללים ובוחרים "Add to Home Screen" / "הוספה למסך הבית".

לאחר ההתקנה האפליקציה נפתחת במסך מלא כמו אפליקציה רגילה, עם האייקון שהגדרנו.

## מגבלה חשובה: זיהוי קול ב-iPhone

**Safari באייפון לא תומך ב-Web Speech API** (זיהוי הדיבור בדפדפן) - זו מגבלה של אפל, לא של האפליקציה. המשמעות:
- ב**אנדרואיד/כרום** ו**מחשב עם כרום/אדג'** - כפתור ה-Push-to-Talk יעבוד.
- ב**אייפון** - כפתור המיקרופון לא יופיע, אבל הרישום המהיר (הקשה על שחקן ואז מושג) וההקלדה הידנית עובדים בכל מכשיר ללא תלות בזה.

אם בעתיד תרצי זיהוי קול אמיתי גם באייפון, הפתרון היחיד הוא Cloud Function (שרת) שמקבל קובץ אודיו ושולח אותו לשירות תמלול חיצוני - זהו פרויקט נפרד.

## מה שונה מהגרסה שרצה בתוך הצ'אט של קלוד

- **אין יותר שכבת AI חופשית (Claude) לזיהוי ניסוחים** - זו הייתה זמינה רק בסביבת ה-artifact הפנימית של claude.ai בחינם וללא מפתח. כאן, כל משפט שלא מזוהה מול בנק המושגים עובר לשיוך ידני. אפשר להוסיף את זה בעתיד עם Cloud Function שמחזיק מפתח API בצד השרת (לא בצד הלקוח).
- **הרשאות אמיתיות**: אושרו/נחסמו על ידי כללי Firestore בפועל (לא רק בממשק), ומגובות בהתחברות אמיתית (Firebase Auth) במקום שם+קוד חופשי.
- **סנכרון בזמן אמת בין מכשירים**: אם כמה אנשים (מאמן בקהל + מישהו במועדון) פותחים את האפליקציה יחד, כולם רואים את אותו משחק, אותו שעון ואותה סטטיסטיקה מתעדכנים בזמן אמת (Firestore realtime).

## מבנה הקבצים

```
index.html          - עמוד הבית
app.js               - כל הלוגיקה (Auth, Firestore, ממשק)
styles.css           - עיצוב (שחור/כחול)
firebase-config.js   - המפתחות של פרויקט ה-Firebase שלך (יש להחליף)
firestore.rules      - כללי אבטחה - יש להעלות לקונסולת Firebase
manifest.json        - הגדרות PWA
sw.js                - Service Worker (עבודה אופליין של קבצי האפליקציה)
logo.png             - אייקון האפליקציה
icons/               - גדלי אייקון נוספים (ל-PWA ול-iOS)
```
